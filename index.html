What is Machine Learning?

Machine Learning is a branch of Artificial Intelligence that allows computers to learn from data and improve their performance without being explicitly programmed for every decision.

Types of Machine Learning

Machine Learning can be divided into different approaches depending on how the machine learns.

🎯

Supervised Learning

The model learns from data that already has known answers.

Example: Predicting house prices.

🔍

Unsupervised Learning

The model finds patterns and groups in data without predefined answers.

Example: Customer segmentation.

🎮

Reinforcement Learning

An agent learns by interacting with an environment and receiving rewards or penalties.

Example: Game-playing AI.
